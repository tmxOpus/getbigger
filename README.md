# GetBigger

Дневник питания и план тренировок для спортсменов. Одна страница без сборки и сервера, все данные хранятся на устройстве.

- расчёт калорий и БЖУ под цель (набор, сушка, сила, выносливость, поддержание);
- план силовых тренировок с упражнениями, подходами и отдыхом;
- дневник еды: сколько осталось добрать и чем;
- список научных источников, на которых основаны расчёты, во вкладке «Источники».

## Установка на телефон

Откройте страницу и нажмите «Установить». На iPhone: Safari → «Поделиться» → «На экран „Домой“». После установки приложение работает без интернета.

## Защита данных

- Данные хранятся только на устройстве и никуда не отправляются.
- Профиль и дневник лежат в `localStorage` в зашифрованном виде (AES-256-GCM, Web Crypto). Ключ создаётся автоматически при первом запуске и хранится в IndexedDB как неизвлекаемый. Паролей нет.
- В разделе «Профиль → Защита данных» можно скачать резервную копию (открытый JSON), восстановиться из неё и стереть все данные.
- Страница отдаётся со строгой Content-Security-Policy: скрипты только свои, сетевые запросы только к своему адресу.
- Ключ лежит на том же устройстве, поэтому шифрование защищает от чтения файлов хранилища, но не от человека или программы с доступом к открытому приложению.

## Запуск локально

```bash
python3 -m http.server 8765
```

Приложение не заменяет врача и тренера.
